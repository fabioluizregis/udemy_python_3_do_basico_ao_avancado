## Pré-requisitos
- Python 3.8+ instalado
- Ambiente virtual recomendado (`venv` ou `virtualenv`)

## Como usar
1. Clone o repositório:

```bash
git clone https://github.com/SEU_USUARIO/udemy_python_3_do_basico_ao_avancado.git
cd udemy_python_3_do_basico_ao_avancado
```

2. Crie e ative um ambiente virtual (opcional, recomendado):

```bash
python -m venv .venv
source .venv/Scripts/activate    # Windows (PowerShell): .venv\Scripts\Activate.ps1
```

3. Execute um exercício específico:

```bash
python exercicios/aula1.py
```

Observação: Alguns exemplos podem depender de pacotes externos. Verifique cada aula e instale dependências conforme necessário.
